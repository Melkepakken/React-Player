How React Player works

Viewers send supported media links. React Player checks them, adds valid requests to one queue, and lets you or your moderators control playback from the OBS dock.

  1. Link sent

    A viewer sends a link through chat or another Streamer.bot event.

  2. Link checked

    React Player extracts the first supported link and validates it.

  3. Added to queue

    Valid requests wait in the queue. Autoplay is optional.

  4. You control it

    Play and manage requests from the dock. Moderators can help too.

Setup

Import the package, enable the local connection, then add the player and dock to OBS.

Before you begin You need OBS and Streamer.bot. Streamer.bot must already be connected to OBS.
1

Download and import

Download React Player
  1. In Streamer.bot, click Import.
  2. Drag React-Player-Import.txt onto the Import String box.
  3. Leave the included items selected and click Import.
Done when: You see React Player - by Melkepakken in Streamer.bot.
2

Start the local WebSocket

  1. Open Servers/Clients > WebSocket Server.
  2. Turn on Auto Start and start the server.
  3. Use the defaults: 127.0.0.1 · 8080 · endpoint /.
Done when: The Streamer.bot WebSocket server is running.
3

Add the player to OBS

  1. Add a new Browser source in OBS. Name it anything.
  2. Paste the Player URL and set the source size to match your OBS canvas.
https://react.melkepakken.tv/v1/player/
4

Add the dock to OBS

  1. Open Docks > Custom Browser Docks.
  2. Name it React Player and paste the Dock URL.
https://react.melkepakken.tv/v1/dock/
Done when: The dock is visible and says Connected.
Setup complete Paste a supported link into the dock whenever you want to add a request.
Streamer.bot → OBS

Connect Streamer.bot to OBS

If Streamer.bot already controls your OBS, you can skip this.

  1. In OBS, open Tools > WebSocket Server Settings.
  2. Turn on Enable WebSocket server. Keep port 4455.
  3. In Streamer.bot, open Stream Apps > OBS.
  4. Add an OBS WebSocket v5 connection.
  5. Use host 127.0.0.1 and port 4455.
  6. Enter your OBS password only if you set one, then connect.
Website → Streamer.bot

Streamer.bot WebSocket settings

The React Player website talks to Streamer.bot through its local WebSocket server.

  • Address127.0.0.1
  • Port8080
  • Endpoint/

Viewer requests

Enable !sr

Enable the React Player Request command in Streamer.bot.

!sr · !request · !react · !reactrequest · !addvideo
Chat scanner

Scan normal chat for links

Enable - React Player: Scan Chat and the chat trigger for each platform you want.

StreamElements

Accept links from tips

Enable - React Player: StreamElements Tip. Edit its trigger if you want your own tip rules.

Vote skip

Let viewers vote to skip

Enable - React Player: Vote Skip and its command. Default threshold: 3.

!voteskip · !vskip
Mod controls

Give moderators chat controls

Enable only the included React Player command objects you want your moderators to use.

Custom events

Bits, subs, rewards and more

Use the example triggers inside React Player: Add Link, or connect any Streamer.bot event that provides a link.

The dock says Not connected
  • Make sure Streamer.bot is running.
  • Check Servers/Clients > WebSocket Server.
  • It should be running on 127.0.0.1, port 8080, endpoint /.
  • If your browser asks for local network access for react.melkepakken.tv, allow it.
The dock cannot find the OBS player

Check that your OBS Browser Source uses the exact Player URL:

https://react.melkepakken.tv/v1/player/
OBS controls do nothing

Streamer.bot is probably not connected to OBS. Open Connections above.

Viewer or moderator commands do not work

React Player commands are disabled by default. Open Extras above and enable the commands you want.
